## Unit?을 리턴하지 말라

`Unit?`은 `Unit` 또는 null이라는 값을 가질 수 있다.
따라서 `Boolean`과 `Unit?`은 서로 바꿔서 사용하루 수 있습니다.

```
fun keyIsCorrect(key: String): Boolean = //...

if(!keyIsCorrect(key)) return
```
다음 코드처럼 사용할 수도 있다.
```
fun verifyKey(key: String): Unit? = //...

verifyKey(key) ?: return
```

이런 코드는 작성할 때는 멋있게 보일수도 있지만 읽을때는 그렇지 않다.
Unit?으로 Boolean을 표현하는 것은 오해의 소지가 있으며, 예측하기 어려운 오류를 만들 수 있다.

```
getData()?.let { view.showData(it) } ?: view.showError()
```
이 코드는 showData가 null을 리턴하고, getData가 null이 아닌 값을 호출할 때, showData와 shwError을 모두 호출한다.

이러한 코드보다 if-else 조건문을 사용하는 것이 훨씬 이해하기 쉽고 깔끔하다.

따라서 기본적으로 Unit?을 리턴하거나 이를 기반으로 연산하지 않는 것이 좋다.
